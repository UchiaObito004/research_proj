Enterprise Fault-Tolerant Scaling

Kubernetes Autoscaling (HPA)

Guarantees the system never crashes when concurrent traffic surges. Automatically replicates pods from 3 to 15 instances based on CPU and memory thresholds.

☸️

Horizontal Pod Autoscaler

Scales pod replicas dynamically from 3 to 15 instances when CPU exceeds 70% or RAM exceeds 80%. When traffic spikes, new worker pods spin up in seconds.

minReplicas: 3
maxReplicas: 15
targetCPU: 70%
🛡️

Zero-Downtime Rolling Updates

Kubernetes ensures zero downtime (maxUnavailable: 0). Liveness and readiness probes verify model weight integrity before routing incoming HTTP traffic.

strategy: RollingUpdate
maxSurge: 1
maxUnavailable: 0
⚖️

LoadBalancer & Ingress

Distributes incoming multipart image requests evenly across healthy worker pods, preventing memory saturation and thread starvation during peak industrial sorting operations.

type: LoadBalancer
port: 80 -> 8000
protocol: TCP
